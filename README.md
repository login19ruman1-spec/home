# DomeGuard 1.5.1

Обновление для верхней границы Незера и DomeVoid.

## Что исправлено
- Игрок за верхней границей Незера попадает в DomeVoid вместо смерти.
- Void-урон в DomeVoid отменяется.
- Игрок появляется на стартовой платформе и может строить/ломать блоки.
- При падении ниже безопасной высоты игрок возвращается на платформу.
- В DomeVoid есть портал обратно в сохранённую точку Незера.
- Убраны сообщения о проклятии.
- Проклятие теперь выдаётся именно умершему игроку после смерти за пределами настроенной территории.
- Проклятие сохраняется в curses.yml.
- Подозрительный суп снимает проклятие.

## Установка
1. Распакуй ZIP.
2. Открой папку `DomeGuard15` в GitHub/репозитории.
3. Не добавляй строки Markdown ` ``` ` в Java-файлы.
4. Запусти GitHub Actions.
5. После зелёной сборки возьми `target/DomeGuard-1.5.0.jar`.
6. Замени старый JAR на сервере и перезапусти Paper.

## Важно
Существующий мир `DomeVoid` сохраняется. Стартовая платформа создаётся только если центральная площадка ещё пустая.
