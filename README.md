# DomeGuard v1.2.0

Плагин для Purpur/Paper 1.21.4.

## Что нового в v1.2

- Независимый радиус по X и Z: можно сделать эллиптическую территорию.
- Верхняя и нижняя границы Y настраиваются отдельно.
- GUI обновлён: отдельные кнопки для X и Z.
- За границей: тошнота, нарастающий урон, сильная Darkness + Blindness и звуки Вардена.
- В глубокой зоне воспроизводятся звуки сердца/окружения Вардена.
- Смертельная зона и автоматический респавн через 3 секунды.
- Настройки сохраняются в `plugins/DomeGuard/config.yml`.

## Команда

`/dome` — открыть меню. Требуется `dome.admin` (по умолчанию OP).

## Геометрия

Горизонтальная граница — эллипс:

`(dx / radius-x)^2 + (dz / radius-z)^2 <= 1`

Поэтому X и Z можно настроить независимо.
